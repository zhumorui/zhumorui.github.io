# Repository Guidelines

## Git commits

- **NEVER include any Claude/AI attribution in commits** — no `Co-Authored-By: Claude` trailers, no "Generated with Claude Code" lines, nothing that indicates AI involvement.
- **Commit messages must be generic and neutral.** Never describe personal or private details (employers, internships, affiliations, contact info, etc.) in commit messages — use vague wording like "Update CV" or "Update content" instead.
- Do not push to the remote without the user's explicit request.
